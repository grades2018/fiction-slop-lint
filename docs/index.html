fiction-slop-lint

A style linter for fiction manuscripts. Paste a scene or load a file, and see cliches, overused phrases, repetition and rhythm habits flagged.

Private by design. The check runs in your browser with the same rules file the command line tool uses. Your text is not uploaded, stored or tracked. This is a style linter, not an AI detector: a hit means "worth a look", never proof of how text was written.

    Rules live in a single human-editable rules.json. See the repository for the command line tool (Python, no dependencies), the rule list and limitations. Expect false positives: a flagged cliche may be exactly what your character would say.

    A note on publishing: Amazon KDP requires authors to disclose AI-generated text when they publish. This tool does not change that duty and does not help anyone avoid it. Read KDP's current content guidelines for the exact wording.
